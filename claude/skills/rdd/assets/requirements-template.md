## 0. テンプレート宣言と記述ルール

- 本書は製品の振る舞い（何を満たすか）のみを記述する。設計・実装方式・計画・タスクは含めず、ID で参照する
- 強度表現（「なるべく」「できるだけ」等）は使わない

### ID 体系

| 接頭辞 | 対象 | 形式 |
| --- | --- | --- |
| FR | 機能要件 | `FR-001` |
| AC | 受け入れ基準 | `AC-FR-001-1` |
| NFR | 非機能要件 | `NFR-001` |
| SEC | セキュリティ・プライバシー要件 | `SEC-001` |
| EXC | 例外・エラー時の振る舞い | `EXC-001` |
| ASM | 前提 | `ASM-001` |
| DEP | 依存 | `DEP-001` |
| CON | 制約 | `CON-001` |
| RSK | リスク | `RSK-001` |
| Q | 未決事項 | `Q-001` |

- 連番は 3 桁、種別ごとに採番する。
- ID は一度付けたら変更・再利用しない。廃止時は欠番とし、状態を「廃止」にして残す。
- 数値は単位を必ず付ける（例: `200 ms`, `99.9 %`）。表記は文書全体で統一する。
