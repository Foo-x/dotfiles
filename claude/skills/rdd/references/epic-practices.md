# EPIC 品質基準

出典: https://epicframework.netlify.app （仕様駆動開発における仕様成果物の品質フレームワーク）。
ここには要旨とテンプレート節への対応だけを書く。各プラクティスの定義・根拠・例は出典を参照する。

4 カテゴリ・10 品質次元・40 プラクティスで構成され、次元ごとに 0〜3 点で採点して合計 30 点満点とする。

## 次元とプラクティス

節番号は `assets/requirements-template.md` の節を指す。

## 採点基準

| 点 | 目安 |
| --- | --- |
| 0 | 該当する記述がない |
| 1 | 一部にあるが、欠落や不統一が多い |
| 2 | 大半で満たすが、例外が残る |
| 3 | 文書全体で一貫して満たし、根拠を引用できる |

### 採点時の注意

- 3 点は、一箇所の優れた記述ではなく、全体で一貫している場合だけに付ける
- 未記入のプレースホルダ（`<...>`）は根拠にならない
- 長さは品質ではない。記述量でなく、本文の引用で根拠を示す
- 該当しないプラクティスは N/A とし、理由を書く
- 各次元で、満たしている点・欠けている点・根拠（節番号と引用）を書き、改善は影響の大きい順に並べる
