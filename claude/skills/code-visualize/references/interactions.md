# インタラクションの選定と実装規約

インタラクションは理解を助ける場合だけ使う。初期表示は概観しやすいよう情報量を絞り、詳細は操作で出す。

## 実装規約

- コード要素のデータ・図のデータ（ノード・辺・遷移・条件）は `<script type="application/json">` に1か所で持ち、描画ロジックと分離する
- 素の JS で書く。標準要素を優先する（`<button>` `<details>` `<dialog>` `<input type="range">` `<select>`）
- 要素は `data-code` でコード要素に紐づけ、イベントは親要素で委譲して処理する
- 状態（選択中のタブ・条件・ステップ）は1つの state オブジェクトに持ち、変更時に再描画する。URL ハッシュに保存し、リロード・共有で再現できるようにする
- キーボード操作できること（フォーカス可能、Enter/Space で実行、Esc で閉じる）。`aria-*` を付け、色だけに依存しない
- 評価ロジック（条件切替・遷移）には、根拠の C と `file:line` をコードのデータ側に持たせ、結果表示に併記する

## 詳細表示の部品の使い分け

| 部品 | 使う場面 |
|---|---|
| ツールチップ | 一目で足りる短い補足（ID の内容、要素名、`file:line`）。ホバー/フォーカスで表示 |
| ポップアップ | 要素の近くに出す中程度の詳細（シグネチャ、フィールド一覧）。クリックで開閉 |
| ドロワー | コード抜粋（行番号付き）・関連するコード要素など長い詳細。図を見たまま読めるよう横に出す |
| ダイアログ（`<dialog>`） | 注意を要する情報や、操作の結果の確認。閉じるまで他を操作させない |
| アコーディオン（`<details>`） | 図の外の補足、一覧の折りたたみ |

## パターン

### 1. 段階的詳細表示

- 適用: 要素が多い、または要素ごとの説明が長い
- 方法: 初期は名前だけ・抽象度の高い単位で表示し、ホバー/クリックで詳細を出す
- ★ サブグラフ（パッケージ・モジュール・階層状態・プロセス分解）を1ノードに折りたたみ、クリックで展開する（意味的ズーム）

### 2. 条件切替シミュレーション

- 適用: 条件によって結果が変わるコード（分岐・バリデーション・閾値）
- 方法: 入力 → 評価関数 → 結果表示。入力部品は条件の型で選ぶ
    - 数値の範囲: スライダー（現在値を数値でも表示）
    - 真偽: トグル/チェックボックス
    - 排他的な選択肢（enum など）: ラジオ/ドロップダウン
    - 自由入力: テキストボックス（不正入力のときの結果もコードに従って示す）
- ★ シナリオプリセット: 代表ケース（正常・境界値・異常）を1クリックで条件一式に設定する
- ★ 制約の充足表示: 満たす/違反する制約を色と記号で分け、違反理由と根拠のコード箇所を示す
- ★ 決定表の該当ルールのハイライト

### 3. 遷移・時間の再生

- 適用: 遷移の方法やタイミングが重要なコード
- 方法: ボタンでイベントを発火し、現在の状態を強調、前後の状態・発火したイベント・副作用を表示する。リセットボタンを置く。発火できないイベントは無効化し、理由（ガード）を表示する
- ★ ステップ送り/戻し、自動再生（速度調整）、スクラバーで任意時点へ（シーケンス図・トレース表・タイミング）
- ★ ペトリネットのトークンゲーム: 発火可能なトランジションだけ有効化し、クリックでトークンを移動する。発火可能なものがなくなったらデッドロックとして表示する

### 4. タブ切替

- 適用: 並列関係のコード要素（モジュール別、エントリポイント別、正常/異常）
- 方法: タブで即時に切り替える。タブ間で共通の凡例・選択状態は保つ
- ★ 同じデータの別ビューの切り替え（シーケンス⇔コミュニケーション、構造⇔インスタンス、表⇔グラフ）

### 5. 階層移動

- 適用: 階層構造のコード（パッケージ→モジュール→型→メソッド）
- 方法: 階層ツリーとパンくずを併用する。パンくずで上位に戻り、ツリーで兄弟へ移動する

### 6. ★ 選択連動ハイライト

- 適用: 要素同士の関係をたどりたい（依存・呼び出し・データフロー）、複数の図に同じコード要素が現れる
- 方法: 要素の選択で上流/下流・到達経路・影響範囲を強調し、他を減光する。同じ `data-code` を持つ他の図の要素とコード抜粋も強調する
- ★ 2点間の経路: 2つの要素（関数・モジュール）を選ぶと、その間の呼び出し/依存/データの経路をすべて強調する（コールグラフ・依存関係グラフ・データフロー図向け）

### 7. ★ 検索・フィルタ・レイヤー

- 適用: 要素が多い、観点が複数ある
- 方法: キーワード、ファイル/モジュール、可視性（公開/非公開）、同期/非同期、正常/異常系で絞り込む。凡例のクリックで種別の表示/非表示を切り替える
- レイヤー: 推定で補った箇所・図に未反映のコード要素を重ねて表示/非表示できるようにする

### 8. ★ 比較表示

- 適用: 条件やシナリオの違いによる結果の差を見たい
- 方法: 2つの条件・シナリオの結果を並べ、差分を強調する

### 9. ★ ズーム・パン

- 適用: ノード数が多い図（目安: 30ノード超）に限る。他の図では使わない
- 方法: ボタン（＋/－/リセット）とホイール/ドラッグで操作する。`viewBox` を変更して実装する
